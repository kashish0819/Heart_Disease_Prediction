Heart Disease Prediction System
📌 Project Overview

This project is a Machine Learning-based Heart Disease Prediction System that predicts whether a patient is at high or low risk of heart disease based on clinical and medical attributes.

The system analyzes patient health indicators such as age, cholesterol level, blood pressure, chest pain type, maximum heart rate, and other medical parameters to provide risk predictions.

A user-friendly Streamlit web application has been developed for real-time patient risk assessment.
🎯 Objectives
Analyze heart disease patient data
Perform data cleaning and preprocessing
Conduct Exploratory Data Analysis (EDA)
Build and evaluate machine learning models
Compare model performance
Identify important clinical risk factors
Develop a real-time prediction interface
